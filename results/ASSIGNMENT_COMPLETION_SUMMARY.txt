======================================================================
LESSONS LEARNED & INSIGHTS
======================================================================

1. Data Quality is Critical
   - Synthetic audio unsuitable for ASR evaluation
   - Real data essential for meaningful results
   - Quality directly impacts all downstream tasks

2. Multilingual Challenges
   - Hindi-English code-switching common
   - Transliteration variations need handling
   - Spellcheckers need domain knowledge

3. Evaluation Fairness
   - Single reference gold standard is unfair
   - Multiple valid representations must be recognized
   - Lattice structure enables semantic fairness
   - Traditional metrics can penalize correct answers

4. Pipeline Architecture
   - Modular design enables reusability
   - Clear separation of concerns
   - Extensible for new features
   - Easy to integrate with external tools

5. Hindi Language Specifics
   - 120+ ways to express numbers
   - Script varies (diacritics, nuktas)
   - Compound verb forms are common
   - Code-switching with English prevalent
